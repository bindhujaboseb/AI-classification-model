🎯 Learning Objective

The students will be able to explain image classification and build and test an image classifier that recognises hand gestures.

✅ Success Criteria

  • I will be able to explain classification as sorting pictures into classes.
  • I will be able to collect 20+ pictures per class and train the model.
  • I will be able to test each hand sign and explain the confidence (%).
  • I will be able to justify why the AI is wrong for a new sign and suggest how to improve the data.
